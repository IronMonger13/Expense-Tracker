# Expense Tracker

A personal finance management web application built with **Python and Django** that helps users track their income and expenses, monitor spending habits, and manage their finances through an intuitive dashboard.

## Overview

Expense Tracker provides a centralized platform to record and manage financial transactions. It offers a dashboard with an overview of total balance, income, expenses, and savings, along with category-wise spending breakdowns to help users understand where their money goes.

## Features

- **Dashboard:** View total balance, income, expenses, and net savings at a glance.
- **Transaction Management:** Add, view, edit, and delete income and expense transactions.
- **Category Management:** Organize transactions using predefined financial categories.
- **Spending Snapshot:** Visualize expenses across different categories.
- **Recent Transactions:** Quickly access recently recorded transactions.
- **Financial Reports:** Review financial activity and spending patterns.
- **Confirmation Alerts:** Receive notifications for successful actions and confirmation before destructive operations.
